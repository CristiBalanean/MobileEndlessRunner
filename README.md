# 🏎️ Highway Dash

A 2D endless runner arcade racing game built with Unity and published on Google Play under the [Ordeal Games](https://ordeal-games-website.vercel.app/) studio.

📲 **Download:** [Highway Dash on Google Play](https://play.google.com/store/apps/details?id=com.OrdealGAMES.HighwayDash)

---

## About

Highway Dash is a fast-paced mobile game where players dodge traffic, collect rewards, and survive as long as possible on an ever-accelerating highway. It evolved from an [early prototype](https://github.com/CristiBalanean/Portofolio-Games/tree/main/Car-Game) into a fully shipped product — designed, developed, and published as a solo developer.

---

## Features

- Swipe-based touch controls optimized for mobile
- Procedurally spawning traffic and obstacles
- Score tracking and progression system
- 50+ original assets — characters, vehicles, backgrounds, and animations
- Performance-optimized for smooth gameplay on mid-tier Android devices

---

## Tech Stack

- **Engine:** Unity
- **Language:** C#
- **Shaders:** ShaderLab, HLSL (custom visual effects)
- **Build & Release:** Android build pipeline, Google Play Console
- **Version Control:** Git
